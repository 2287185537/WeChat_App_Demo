# 番茄时钟微信小程序

这是一个简单易用的番茄时钟微信小程序，旨在帮助用户提高工作效率和专注度。

## 主要功能

*   **核心番茄钟**：标准的番茄工作法流程，包含工作时间和休息时间。
    *   启动、暂停、重置计时器。
    *   工作/休息时间结束后自动切换。
    *   时间以 `MM:SS` 格式清晰显示。
*   **自定义工作时长**：
    *   用户可以通过滑块自定义每个工作时段的长度（默认为25分钟，范围5-60分钟）。
*   **任务记录**：
    *   用户可以输入当前正在进行的任务名称，以便更专注于当前事项。
*   **简洁界面**：
    *   直观的计时器显示和控制按钮。
    *   清晰的当前任务和会话类型（工作/休息）提示。
*   **声音提示 (Sound Notifications)**：
    *   在每个工作或休息时段结束时，会发出声音提醒。
    *   用户可以在界面上方便地开启或关闭声音提示。
*   **统计与历史记录 (Statistics and History)**：
    *   应用会记录用户完成的番茄钟数量。
    *   用户可以查看已完成任务的历史列表（包含任务名称和完成时间）。
    *   提供清空历史记录的功能。
*   **动态色彩方案 (Dynamic Color Scheme):** 界面背景色会根据当前会话类型（工作/休息）以及计时器进度动态变换，提供更具沉浸感的状态指示。工作时为莫兰迪红色渐变，休息时为草木绿色渐变。

## 如何使用

1.  **环境准备**：
    *   下载并安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2.  **导入项目**：
    *   打开微信开发者工具。
    *   选择“导入项目”。
    *   AppID：建议使用测试号或您自己的 AppID。
    *   项目名称：自定义。
    *   目录：选择本项目的根目录。
3.  **运行与测试**：
    *   点击“编译”按钮，即可在模拟器中查看和测试小程序。
    *   可以设置工作时长，输入任务，并开始番茄钟。

## 项目结构简介

*   `app.js`, `app.json`, `app.wxss`: 小程序全局配置和样式。
*   `pages/index/`: 主要的番茄时钟页面，包含计时器逻辑、界面布局和样式。
    *   `index.js`: 页面逻辑。
    *   `index.wxml`: 页面结构。
    *   `index.wxss`: 页面样式。
*   `utils/`: 可能包含一些通用工具函数（当前项目中`util.js`为默认生成）。
